# Synthetic sample data

Every resume, person, company and job posting in this directory is fictional and was
generated by `scripts/build_sample_data.py` for testing and demonstration. Contact
details use reserved example domains. Do not treat these documents as real candidates.

- `resumes/` - PDF, DOCX and TXT variants across single-column, two-column and table layouts.
- `jobs/` - 23 synthetic job postings as JSON and CSV (one intentionally unstructured).
- `fixtures/` - corrupt, empty and image-only PDFs plus an unsupported file type.
- `manifest.json` - resume/job IDs with content hashes used by evaluation scripts.
